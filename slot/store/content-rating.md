# İçerik derecelendirme (IARC) — anket cevapları

Aynı anket hem Google Play'de (IARC) hem de App Store'da (Apple'ın kendi formu) sorulur.

| Soru | Cevap |
|---|---|
| Şiddet (gerçekçi / karikatür / fantastik) | Yok |
| Kan gösterimi | Yok |
| Cinsellik veya çıplaklık | Yok |
| Küfür / argo | Yok |
| Uyuşturucu, alkol, tütün | Yok |
| Korku / dehşet öğeleri | Yok |
| **Kumar (gerçek veya simüle)** | **Yok** — uygulamanın adı "Slot" olsa da içinde slot makinesi, çark, kart, bahis, sanal para veya herhangi bir şans öğesi yoktur. "Slot", oyuncunun geçmesi gereken yarıktır. Sonuç yalnızca oyuncunun zamanlamasına bağlıdır. |
| Kullanıcılar arası etkileşim, sohbet, çok oyunculu | Yok |
| Kullanıcı konumu paylaşımı | Yok |
| Kullanıcı tarafından oluşturulan içerik | Yok |
| Dijital satın alma içeriyor mu? | **Evet** (tek seferlik "Remove Ads") |
| Reklam içeriyor mu? | **Evet** (banner yok; geçiş + isteğe bağlı ödüllü video) |
| Harici bağlantı içeriyor mu? | Evet — gizlilik politikası, kullanım şartları ve destek sayfası |

## Beklenen sonuç
| Bölge | Derece |
|---|---|
| Apple | **4+** |
| ESRB (ABD) | Everyone |
| PEGI (Avrupa) | PEGI 3 |
| USK (Almanya) | USK 0 |
| Google Play genel | Herkes |

> **Kumar sorusunda tereddüt etme.** Bu soruya yanlışlıkla "evet" dersen derecelendirme
> 18+'a çıkar, bazı ülkelerde dağıtım kapanır ve AdMob envanterinin bir kısmı düşer.
> Doğru cevap "yok"tur; gerekçesi yukarıda ve `docs/terms.html` madde 4'te yazılı.

> Dikkat: "Dijital satın alma" ve "reklam" işaretlendiği için bazı bölgelerde
> derecelendirmenin yanında "In-app purchases" / "Contains ads" etiketi görünür. Bu normaldir.
